## 1. 단계별 구현 과정 및 학습 내용

### 🔀 Git Open Source Contribution Workflow
* 원본 저장소를 **Fork**한 뒤 개인 작업공간에서 코드를 수정하고, **Pull Request(PR)**를 보내어 코드 리뷰를 받는 일련의 브랜칭 및 협업 방식을 익혔습니다.

### 📁 `pathlib` 모듈을 활용한 파일 시스템 제어
* 기존 `os.path` 대비 직관적이고 객체 지향적인 `pathlib`을 활용하여 파일의 생성, 읽기, 쓰기, 삭제 등 관리를 간편하게 수행했습니다.

### 📄 JSON 데이터 파싱
* Key-Value 쌍으로 구성된 JSON 포맷 문자열을 파이썬 데이터 구조(Dict, List)로 변환하고 자유롭게 다루는 실습을 진행했습니다.

### 🔍 데이터 필터링 조건 작성
* `not in` 연산자를 활용해 조건에 맞는 항목(예: '어린이' 범주를 제외한 도서)을 선별하는 로직을 구현했습니다.

### 🤖 AI 도구 활용 (Prompt Engineering)
* 구현에 필요한 최적의 함수나 알고리즘 추천 프롬프트를 작성해 코드 후보를 도출하고, 이해가 부족한 모르는 코드는 **후속 질문**을 이어가며 단계적으로 코드를 채워나갔습니다.

## 3. 새로 배운 기술 및 핵심 개념

* **JSON 데이터 필터링 & 출력 Pipeline**
  * 외부 JSON 파일 데이터를 로드하여 조건별로 가공·필터링 후 터미널/파일로 출력하는 흐름 구축
* **Git Code Merge & Conflict Handling**
  * 팀원 간 작성한 코드를 하나로 모으고 병합(Merge)하는 전체 흐름 학습
* **Python Advanced Built-ins & Modules**
  * `collections.defaultdict`: 키 부재 에러 방지 및 깔끔한 빈도수/그룹핑 처리
  * `sorted()` & `lambda`: 람다 표현식을 활용한 복합 조건 정렬 알고리즘 적용

## 4. 프로젝트 회고 및 느낀 점

* 🎯 **명세서 기반 프로그래밍의 중요성**  
  요구사항 명세서에 맞추어 단계별로 코드를 완성해 나가다 보니 전체적인 프로그램의 데이터 흐름(Data Flow)을 한눈에 파악할 수 있었습니다.
* 📖 **실제 데이터 구조에 대한 이해**  
  직접 JSON 파일 구조를 불러오고 처리하는 실습을 통해 실무에서 많이 쓰이는 데이터 포맷 형식과 친숙해지는 계기가 되었습니다.
* 🤖 **AI 활용에 대한 되돌아보기**  
  AI가 순식간에 수많은 코드를 생성해 주었지만, 이를 스스로 이해하기 위한 코드 리뷰 과정에 예상보다 많은 시간이 소요되었습니다. 단순히 코드를 복사하는 것이 아니라 **"코드의 동작 원리를 내 것으로 만드는 과정"**이 무엇보다 중요하다는 점을 깨달았습니다.
